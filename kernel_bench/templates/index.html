2. Autonomous Optimization Loop

1. GET /api/status -> check targets (pp512: 3439.99, tg128: 69.16) & latest version
2. GET /api/analyze -> inspect slowest ops & CPU fallbacks (e.g. REF_MUL)
3. GET /api/versions -> review past attempts to avoid duplicate work
4. POST /api/iteration/submit -> submit idea & new CUDA kernel code
5. GET /api/jobs/{job_id} -> poll until status == 'completed'
6. Repeat until target_beaten == true!

3. Python Client Example

import requests

bench_url = "http://localhost:8080"
status = requests.get(f"{bench_url}/api/status").json()
print("Current best:", status["current_best"])

# Submit optimization
job = requests.post(f"{bench_url}/api/iteration/submit", json={
    "idea": "Non-contiguous CUDA Multiply Kernel",
    "filename": "kernels/cuda/mul/NC_F32_ND.cu",
    "source": "<kernel code>",
    "backend": "cuda"
}).json()
print("Job queued:", job["job_id"])
